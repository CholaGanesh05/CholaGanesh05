## 🔬 Research & Publications

**RAC-FraudNet: Bandit-Guided Continual Learning for Fraud Detection** — *IEEE ICMCSI 2025*
First Author. Continual-learning fraud detection system (Prototype-Based DistilBERT + bandit controller, EWC, dual-memory replay) — 99.7% recall at 4.34ms latency, under 1% catastrophic forgetting.

**Multimodal AI Framework for Skin Disease Diagnosis** — *Procedia Computer Science, FTNCT'08 / ScienceDirect 2025*
First Author. MAGE-V-Pro fuses DINOv2 visual encoders with PubMedBERT text embeddings via FiLM cross-modal fusion — 95.71% diagnostic accuracy.

**Research Interests:** LLMs & Agentic AI · Graph Neural Networks · Multimodal AI · Efficient ML
